# Tangará Zeladoria V31

- Perfis: Colaborador, Morador e Síndico.
- Morador: interface simples, registrar pendência com foto e consultar pendências em modo somente leitura.
- Morador não edita checklist, ocorrências, materiais ou compras.
- Síndico: acesso gerencial e único perfil com exportação da lista de pendências e das listas de materiais/compras.
- Interface inicial reorganizada por perfil para reduzir opções desnecessárias.
- Navegação inferior adaptada ao perfil.
- Dados permanecem armazenados no aparelho via localStorage.
