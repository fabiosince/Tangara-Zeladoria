# Tangará Zeladoria V5.1

Versão mobile do sistema de zeladoria do Condomínio Tangará.

## Novidades da V5.1
- Menu **Mais** com acesso claro a Histórico, Relatórios e Perfil.
- Botão **Sair do aplicativo** disponível em Perfil.
- Ao sair, a sessão salva é removida e a tela de login volta a aparecer.
- Cache/service worker atualizado para V5.1.
- Registros locais preservados na chave `tangaraV5.1`.

## Publicação
Envie `index.html`, `sw.js`, `manifest.json` e `icon.svg` para a raiz do branch `main` do GitHub Pages.
