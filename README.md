# Tangará Zeladoria V25

Evolução da V24 com foco em praticidade e leitura rápida da tela inicial.

## Novidades
- Painel "O que precisa de atenção" para Síndico e Administradora.
- Painel "Próximas ações" para Colaborador.
- Ações diretas para ocorrências, pendências e checklist.
- Mantidos os fluxos validados das versões anteriores: ocorrências Aberta/Resolvida, materiais, compras e exportações.
- Perfil Síndico disponível no login.
- Logo atual do Tangará Residencial preservado.
